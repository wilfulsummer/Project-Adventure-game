ROOT CAUSE:
The issue was in the data flow between `command_handlers.py` and `main.py`. While the `handle_attack` function was correctly updating the local `player_money` parameter and printing "You found X gold!", this updated value was not being passed back to the global `player_money` variable in `main.py`.

The problem occurred because:
1. `handle_attack` received `player_money` as a parameter
2. It updated the local copy when enemies dropped gold
3. It returned `updated_stats` dictionary with various statistics
4. However, `player_money` was NOT included in the `updated_stats` dictionary
5. `main.py` received the returned statistics but had no way to update the global `player_money`

SOLUTION IMPLEMENTED:
1. **Modified `command_handlers.py`**: Added `'player_money': player_money` to the `updated_stats` dictionary in the `handle_attack` function
2. **Modified `main.py`**: Added `player_money = updated_stats['player_money']` to update the global variable when unpacking the returned statistics
